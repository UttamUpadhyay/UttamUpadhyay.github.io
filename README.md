
# Flipkart Home Page Clone 🛒

A static web clone of the Flipkart e-commerce homepage, built from scratch using pure HTML and CSS. 

This repository marks my very first web development project! I built this to transition from learning theoretical concepts to writing actual code, focusing on recreating a complex, real-world user interface.

## 🚀 Tech Stack

*   **HTML5:** Used for the semantic structure and content of the web page.
*   **CSS3:** Used for styling, layout formatting, and recreating Flipkart's visual brand identity.

## 🌟 Features Implemented

*   **Navigation Bar:** Recreated the signature Flipkart top header including the logo, search bar UI, and login/cart buttons.
*   **Category Menu:** A horizontal navigation strip for different product categories (Mobiles, Fashion, Electronics, etc.).
*   **Product Grids:** Structured layouts to display product cards with images, titles, and pricing.
*   **Hover Effects:** Interactive CSS styling on buttons and product links to simulate a real user experience.

## 🧠 What I Learned

Building this clone was a massive stepping stone. Through this project, I gained hands-on experience with:
*   **The CSS Box Model:** Understanding margins, padding, and borders to space elements correctly.
*   **Flexbox:** Using `display: flex` to align navbar items and create clean product rows.
*   **Positioning:** Mastering `relative`, `absolute`, and `fixed` positioning for elements like search bars and dropdown menus.
*   **Structuring Code:** Keeping HTML semantic and CSS organized for a large, single-page layout.
